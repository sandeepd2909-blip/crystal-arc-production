RUNNING IT

    npm install
    npm run dev            http://localhost:3000/en

    npm run build          static export into out/

Node 20 or newer. node_modules is not included; npm install rebuilds it.


DEPLOYING

Do not use `netlify deploy --prod` â€” it fails on this account with
JSONHTTPError: Forbidden. The working sequence is:

    npm run build
    netlify deploy --dir=out --no-build        prints a deploy id
    netlify api restoreSiteDeploy --data '{"site_id":"1c042422-bce4-40d4-b56b-ff599a3350b0","deploy_id":"<that id>"}'

`--no-build` is not optional. Without it Netlify rebuilds remotely and the
Next plugin intermittently fails with "Failed publishing static content".
The build has already happened locally; out/ is the finished site.
